## ✨ Features

- **Striking 3-Column Hero Section**: High-contrast dark charcoal cards with smooth hover animations, showcasing Multi-Specialty Care, Expert Doctors, and Advanced Dental & Lab.
- **Interactive Consultation Booking Modal**: Select departments, choose available dates and slots, and receive instant confirmation.
- **Clinical Departments Grid**: Filterable departments (General Medicine, Dentistry, Pediatrics, Cardiology, Orthopedics, Dermatology) with transparent procedure lists.
- **Digital Ecosystem / Patient App**: Highlights the standalone patient mobile app (automated lab report alerts, PDF downloads) and desktop EMR insurance billing.
- **Doctor Profiles**: Detailed credentials, language fluency (English, Arabic, Hindi, Urdu), and direct appointment booking.
- **Location & Working Hours**: Full address, Google Maps GPS directions, and interactive contact inquiry form.

## 🚀 Getting Started

### Prerequisites

- Node.js 18+ (tested on Node v24)
- npm or yarn

### Installation

```bash
git clone https://github.com/armanh148/Happy-Way-Medical-Center.git
cd Happy-Way-Medical-Center
npm install
```

### Running Locally

```bash
npm run dev
```

Open [http://localhost:3001](http://localhost:3001) in your browser.

### Building for Production

```bash
npm run build
npm start
```
